# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Use GitHub's [private vulnerability reporting](../../security/advisories/new)
feature, or contact the maintainer directly via the email on the GitHub profile.

## Known Design Constraints

- The `VITE_API_KEY` is compiled into the frontend JS bundle and is visible
  in the shipped code. The `X-API-KEY` mechanism is a basic access gate for
  internal/pilot deployments, not a substitute for proper access control.
  See README Security & Deployment Notes for the recommended production setup.

- The dev certificate generated by `core/signer.py` is self-signed and will
  not pass public C2PA trust validation. It is for local round-trip testing
  only and is not persisted to disk.

## Supported Versions

Only the latest version on `main` receives security fixes.
